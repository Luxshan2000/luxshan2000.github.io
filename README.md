# Luxshan Thavarasa - Professional Portfolio Website

## Overview
Professional academic-style portfolio website for Luxshan Thavarasa, featuring a clean design with dark/light theme support. Built with modern HTML5, CSS3, and JavaScript for optimal performance and accessibility.

## Features
- ✨ **Dark/Light Theme Toggle** - Seamless theme switching with localStorage persistence
- 📱 **Fully Responsive Design** - Optimized for desktop, tablet, and mobile devices
- 🎓 **Academic Design** - Clean, professional styling suitable for academic portfolios
- 🧪 **Playwright Testing** - Comprehensive test suite for quality assurance
- ⚡ **Fast Performance** - Pure HTML/CSS/JS with no external dependencies
- 🔗 **Smooth Navigation** - Internal anchor links with smooth scrolling

## Sections
- **About** - Professional summary and research focus
- **Experience** - Software engineering roles at H2O.ai and aaivu
- **Education** - Computer Science & Engineering at University of Moratuwa
- **Publications** - Research papers in COLING 2025 and NAACL 2025
- **Projects** - Key projects including DravidaKavacham, QuickChat, and more
- **Skills** - Technical expertise in AI/ML, Full-Stack Development, and more
- **Certifications** - Professional certifications from NVIDIA, H2O.ai, Meta, and Udemy
- **Awards** - Academic and professional achievements
- **Contact** - Professional contact information and social links

## Technical Stack
- **Frontend**: HTML5, CSS3 (CSS Variables), JavaScript ES6+
- **Testing**: Playwright for automated testing
- **Design**: Academic-style responsive design with theme support
- **Performance**: Optimized for fast loading and accessibility

## Theme Support
The website includes a sophisticated dark/light theme system:
- **Light Mode**: Clean white background with blue accents
- **Dark Mode**: Dark background with improved contrast and green link colors
- **Automatic Persistence**: Theme preference saved in localStorage
- **Mobile Optimized**: Theme toggle always accessible on all devices

## Local Development
1. Clone the repository
2. Open `index.html` in a web browser
3. For testing: `npm install` and `npm test`

## Testing
Comprehensive Playwright test suite covering:
- Theme toggle functionality
- Responsive design across devices
- Navigation and anchor links
- Content verification
- Accessibility checks

Run tests:
```bash
npm test                # Headless testing
npm run test:headed     # Visual testing
```

- Full responsive support for mobile devices
